## Reporting a Vulnerability

If you discover a security vulnerability, potential exploit, or unintended exposure of sensitive information, please report it responsibly.

### How to Report

All security-related reports should be submitted through Instagram DM.

**Instagram:** [@holdsauraa](https://instagram.com/holdsauraa)

When reporting, please include:

- A clear description of the vulnerability.
- Steps to reproduce the issue.
- Potential security impact.
- Screenshots, logs, or proof of concept, if applicable.
- Suggested mitigation, if known.

### Responsible Disclosure

- Do not publicly disclose vulnerabilities before they have been reviewed.
- Do not access, modify, or expose other people's private information.
- Do not exploit vulnerabilities against systems without authorization.

### Response Process

Every legitimate report will be reviewed, and reasonable efforts will be made to investigate and address confirmed vulnerabilities.

Please allow sufficient time for investigation before making any public disclosure.

Thank you for helping keep this repository secure.
